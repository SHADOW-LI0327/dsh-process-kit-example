# FEAT-001 电商 app · UI 规格

> **本文件是什么**：把《设计与说明》里**触及 UI 的条目**翻译成**可验收的 UI 规格** —— 界面由哪些组件构成、有哪些交互状态、用户可见文案是什么。它是 test 写 UI 断言的**判据来源**。
> **本文件不是什么**：不是 PRD（判据在 PRD 的 `AC`）、不是契约（字段与签名在 `contracts/FEAT-001.md`）；**不写实现细节**（组件内部结构 / 状态管理选型 / CSS 类名 / 文件路径 / 接口调用细节）。
> **交付物是原型图，而原型图是位图** —— dev 没法从图里机器可读地取色取值。**所以「具体数值」由本件 §八 承担**：颜色 / 间距 / 字号字距 / 圆角全部给出**可直接取用的字面值**。原型图在 `docs/process/prototypes/FEAT-001/`。
> **权威来源**：需求核对件的裁定表（`R-NN`）与《设计与说明》（读的是 `FEAT-001-design.md` **rev 1**，`status: draft` / `gate1: pending`）。**不在本件发明新业务口径** —— 需要新口径时回流 §七 由人裁定。
> **送审时机**：**随 Gate1 一并审**。

> **实现侧分工告知**：只有 `UI-03`（无 `<img>`、首字色块结构）由 test 用 **jsdom / HTTP 静态断言**；`UI-11`（「＋」在 8 时禁用）、`UI-27`（首帧「加载中…」）与 `UI-28`（提交中禁用态）**不在自动化面**，由 **UAT 用真浏览器观察**（截图取证）。这一分工是**主动选择**而非能力受限：结构断言零依赖、快、可重复，且不依赖「本机装了什么浏览器」；**真浏览器渲染与交互不因此没人看** —— 本机确有 Chromium 系浏览器 `/Applications/Microsoft Edge.app`（`Microsoft Edge 155.0.4283.45`，无头 + CDP 实测可用；注意**必须带 `--no-sandbox`**，否则 crashpad 写 `~/Library/Application Support` 被拒 → `sandbox initialization failed` / exit 133），**渲染观感与交互取证由 UAT 用 CDP 承担**（截图 + 点击），截图后交人裁（见 §六 `UD-3`）。

| 加载态 / 错误横幅 / 禁用态 / 订单空态 | **未单独出图**（原因与影响面见 §六 `UD-3`）：取值全部在 §8.2「瞬态态」小节，文案为 §四 `W-22` `W-25` `W-44`~`W-61` | **部分适用**：规格已给全（值 + 逐字文案），但位图未出；这几态的观感未经几何门禁 |

> **多屏命名**：`geometry.json` 与 `geometry.<屏幕名>.json` 并存机制按模板要求采用后者；`intent.<屏幕名>.json` 与几何同名配对（**不是**共用的 `intent.json`），故 ⑤ 居中 / ⑥ 边距对**每一屏**都真实生效（不是空转）。

### 8.2 视觉数值（**dev 直接取用，不要靠肉眼对图**）

> **本次采用 `docs/process/ui/tokens.md` 通用默认令牌，未使用项目专有令牌**（`PROJECT.md` §4「UI 项目令牌」= 不适用）。因此本包视觉语言 = 框架默认层，**不是**项目既有语言。
> **单位纪律**：字号单位是 **point，随文档 ppi 缩放到像素**；本包文档分辨率 **72 ppi** 以保 `1pt = 1px`（144ppi 下文字会被放大一倍）。
> **小字纪律（`tokens.md` 实测结论）**：**12–13px 一律用主文字档 `#e6edf3`，不用次要档 `muted`**（小字笔画覆盖率低，对比度会掉到 4.5:1 以下）；`muted` 只用于 ≥15px。本包实测复核（对 6 张 PNG 逐像素取最亮字像素算比值）：15px 的 `muted` 正文（如「合计」标签）实测 **7.07:1**（= 标称值，字形笔画完全覆盖像素）；**实测最低值 4.62:1 出现在空态页 24px 的 `muted` 空态图标字**（底为 `mutedFill`@0.35 合成色 `#353b43`）—— 它是**大字号**（阈值 3:1）且仍过 4.5:1，属可接受；**唯一逼近阈值的是禁用档步进符号**：`muted` 在 `elevated` 底上标称 6.61:1，半角 `+` 的细笔画实测只有 **4.20:1（判红）** ⇒ 已改为**全角 `＋`/`－`**（笔画覆盖得住像素），实测回到 **5.44:1** 达标（见「瞬态态」小节与 §六 `UD-2` 同类的令牌↔可读性冲突处置）。
